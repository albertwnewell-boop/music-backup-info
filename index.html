Personal desktop utility

My Music Backups

Encrypted, restorable backups of a personal music library and journal from the owner's Mac to the owner's Google Drive.

What the utility does

The live application and SQLite database run locally. A scheduled worker captures a consistent database snapshot, includes journal media and a limited application-source archive, and encrypts the backup with Restic before transferring it through rclone.

A backup is reported as verified only after it has been downloaded into a separate restore directory and its database integrity, relationships, record counts, and file checksums have passed verification.

Why it requests Google Drive access

The owner authorizes the utility to create and manage its backup files in a dedicated Drive folder. It uses the drive.file permission, not blanket permission to read unrelated Drive files. It also checks available storage and verifies the account selected during setup.

What is public here

This website contains only information about the backup utility. It does not host the music application, its source code, journal entries, photos, library records, credentials, or recovery keys. There is no public sign-up or backup-upload service.
